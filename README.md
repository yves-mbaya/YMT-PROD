## GitHub Pages
1. Créer un dépôt GitHub, par exemple `ymt-prod`.
2. Envoyer tout le contenu de ce dossier.
3. Settings → Pages.
4. Deploy from a branch → `main` → `/ (root)`.
5. Enregistrer.
