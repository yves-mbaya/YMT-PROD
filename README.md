- Animations légères

### Publication
1. Créer un dépôt GitHub, par exemple `ymt-prod`.
2. Envoyer tout le contenu du dossier.
3. GitHub → Settings → Pages.
4. Source : Deploy from a branch → `main` → `/ (root)`.
5. Enregistrer.
